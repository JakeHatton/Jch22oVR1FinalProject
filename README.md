What's your project all about?

I wanted to make a game similar to scanner sombre, where the entire environment is found with a Lidar gun. My goal was to create a "story" based theme with the gun, but due to time constraints I did not have the time to do more than a little sample experience.

What was the additional skill you worked on?

so... much... coding. This is a VR development class and I think a good 60% of my project was teaching myself how to code, with the other 40% being unity shenanigans. I have definetly learned a lot from this project, both with unity and coding.

What was a key challenge you overcame or an element of the project you're particularly proud of/want to highlight.

The code wasn't working the day before presentations and somehow I fixed it like 4 hours before class. I didnt even have the time to test it with an actual headset. But it turned out SOOOOO GOOOOD. I'm happy I followed through with the idea despite all the challenges I had to face. Plus this gives me a really good base to start making a Lidar VR game if I wanted to.
